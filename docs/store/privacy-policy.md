# Flashhh privacy policy

Last updated: 14 November 2026 (Europe/London).

Flashhh is a local-first study app. This summary is the in-app placeholder for
store listing review. Replace the contact line before a public release.

## What stays on your device

- Decks, flashcards, study sessions, quiz attempts, and insights are stored in
  an on-device SQLite database.
- Theme and onboarding preferences stay on the device.
- Optional email linking stores a local session token in the platform secure
  store. Google and Apple sign-in are not offered until the account service is
  ready.

## What may leave the device

- PDF bytes and paste-notes leave the device only when you start a generation
  job. The API keeps them only for that job; the app does not retain PDF bytes
  after upload.
- Analytics events, when enabled, never include question text, answers, emails,
  tokens, or file contents.

## Your choices

- Guest mode works fully offline for decks, cards, study, cram, quizzes, and
  insights.
- You can delete decks, cards, and import metadata from the app.
- Cloud sync transport is not connected yet; queued sync rows stay local.
